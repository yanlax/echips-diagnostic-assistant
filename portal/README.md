# Портал service.echips.ru (план и макет)

Портал для сотрудников Echips и подключённых сервисных центров: база знаний (вики, регламенты, чек-листы, схемы,
заводские материалы) и скачивание программ (Echips Hardware Check, образ WinPE, утилиты). **Реализация отложена
до доработки приложений**; сейчас есть только макет дизайна.

## Макет
`design/service-portal.html` — самодостаточный файл (шрифты и логотип вшиты, без внешних загрузок), 4 страницы:
вход, главная, статья базы знаний, программы; тёмная и светлая темы; переключатель «сотрудник / партнёр» показывает
модель прав. Все данные примерные. Пересборка: `python3 portal/design/build.py` (шаблон `design/template.html`,
шрифты и логотип берутся из `src/`).

## Согласованная схема (Yandex Cloud, без VPS)
- Сайт — статика в Object Storage за API Gateway с проверкой входа; вход расширяет существующий сервер (`server/`):
  учётки сервисов (логин + пароль, scrypt), роли admin / сотрудник / партнёр (по организациям), видимость страниц.
- База знаний — Markdown со встроенным редактором (история версий), вложения, поиск, метка «кто видит».
- Программы — релизы при выпуске выкладываются в закрытый бакет и отдаются по временным ссылкам; журнал
  скачиваний (кто, когда, что). Автообновление приложения остаётся через GitHub Releases.
- Этапы: 1) каркас (сайт, вход, роли, страница «Программы», автовыкладка релизов); 2) база знаний;
  3) сервис-партнёры (организации, журнал скачиваний); 4) образ WinPE и раздача.

## Домен
`service.echips.ru`. DNS домена ведёт системный администратор Echips (Яндекс 360). Для подключения понадобятся две
записи: подтверждение владения доменом и CNAME на API Gateway (значения выдаются при запуске этапа 1).
HTTPS-сертификат — Yandex Certificate Manager (бесплатно). Отдельно оценить по тарифу Yandex цену исходящего
трафика при скачивании больших образов WinPE (единицы ГБ).
